# Element June — 개발 로드맵

Element X Android 기반 개인용 수정판. 원본: element-hq/element-x-android (AGPL-3.0).
앱 이름 "Element June", 원본 Element X와 나란히 설치되도록 앱 ID 분리.

## 원칙
- 서버 주소·계정·대화방 ID 등 개인 환경 정보는 코드에 넣지 않는다(로그인 시 입력, 설정은 기기 안에만 저장).
- 추가 기능은 가능한 한 별도 모듈(`features/widgets` 등)로 분리해 원본 업데이트를 따라가기 쉽게 한다.
- 서명 키는 저장소 밖(CI Secrets)에만 둔다.

## 1단계 — 홈 화면 위젯 (먼저 완료)
- [x] 1x1 대화방 버튼 위젯: 배치 시 대화방 선택, 누르면 해당 대화방 바로 열기
- [x] 목록 위젯 4x4, 크기에 따라 5x4 등 반응형 (Jetpack Glance, SizeMode.Responsive)
  - 줄 구성: 왼쪽 대화방 로고, 위 대화방 이름, 아래 최근 메시지 한 줄 (+ 안 읽은 개수)
  - 대화방 순서는 사용자가 직접 지정 (최근 활동 순 정렬 안 함)
  - 각 줄(대화방)을 누르면 해당 대화방으로 바로 이동
- [x] 위젯 설정 화면: 대화방 선택, 끌어서 순서 변경, 위젯별 개별 설정
- [x] 갱신: 새 메시지 알림 처리 시 위젯 갱신 + 주기 갱신
- 잠금화면 가리기 옵션은 넣지 않는다

## 2단계 — 편의 기능 (1단계 성공 후 착수)
- [ ] 실시간 위치 공유 (MSC3489 beacon, 보내기·보기)
- [ ] 사진·파일 여러 개 한 번에 보내기
- [ ] 첨부 후 바로 전송하지 않기: 부연설명을 입력하고 전송할 때 첨부와 설명이 함께 전달
- [ ] 아이디·비밀번호 로그인에서도 기기·세션 관리 (목록, 이름 변경, 로그아웃/삭제 — 삭제 시 비밀번호 재확인)
- ~~메시지 검색~~ — 제외(2026-09-28 결정): 암호화된 방은 기기 안 색인과 과거 메시지 수신이 필요해 성능·자원 부담이 큼. 과거 내용은 별도 도구로 찾음
